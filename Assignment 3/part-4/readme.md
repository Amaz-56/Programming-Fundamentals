## Assignment Overview

Below is a breakdown of the included programs:

*   **Bowling Average Calculator:** A script that calculates a cricket bowler's average by dividing the total runs conceded by the number of wickets taken, including a safeguard to return `0.0` if no wickets were taken[cite: 34, 35].
*   **Word Reverser:** A program that takes a character array (string) from the user, dynamically calculates its length without standard library functions, and reverses the word in-place using a left-and-right pointer swapping mechanism[cite: 36].
*   **2D Array Element Sum:** A script that prompts the user to define the dimensions (rows and columns) of a 2D array, populates it with user input, and calculates the total mathematical sum of all elements within the matrix[cite: 37].
*   **2D Array Subtraction:** A program that reads data into a 2D matrix and systematically subtracts every subsequent element from the initial value stored at the very first index (`[0][0]`)[cite: 38].
*   **Area Calculator (Function Overloading):** A script demonstrating polymorphism via function overloading, utilizing the same `calculateArea` function name to compute either the area of a square (taking one parameter) or a rectangle (taking two parameters)[cite: 39].
