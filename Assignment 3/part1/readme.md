## Assignment Overview

Below is a breakdown of the included programs:

*   **Voltage Calculator:** A program that calculates total electrical voltage by multiplying user-provided values for current and resistance[cite: 16].
*   **Team Player Search:** A program that verifies if a specific player's initial exists within an 11-member squad array, automatically converting uppercase inputs to lowercase for accurate matching[cite: 17].
*   **Word Length Calculator:** A script that determines the length of a user-inputted word by iterating through a character array and counting until a null terminator is reached[cite: 18].
*   **Average Score Calculator:** A program that collects test scores for a specified number of students into an array and calculates their overall average score[cite: 19].
*   **Score Extremes Calculator:** A script that evaluates an array of student test scores to find and display both the highest and lowest scores in the set[cite: 20].
*   **Power Calculator:** A program that takes a base number and an exponent from the user, computing the mathematical power using a standard iteration loop[cite: 21].
