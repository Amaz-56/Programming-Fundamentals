## Folder Overview

This folder is divided into four main parts, each focusing on different programming concepts and complexities. 

### Part 1: Basic Logic & Control Structures
This section covers foundational C++ concepts, including variable assignments, `if/else` control flow, loops, and basic mathematical operations.
* **`question1.cpp` to `question5.cpp`:** Programs dealing with conditional variable assignments, temperature validation, number comparisons, floating-point math, and safe division (preventing division by zero).
* **`question7.cpp` & `question8.cpp`:** Scripts for calculating race standings based on user input and a menu-driven geometry calculator for areas of circles, rectangles, and triangles.
* **`Question9.cpp` & `Question10.cpp`:** Loop-based ASCII value displays using explicit type casting, and a mass-to-weight converter measuring in Newtons.

### Part 2: Menu-Driven Console Applications
This section features larger, structurally complex programs that simulate real-world management, billing, and calculation systems using functions and global variables.
* **`Program6.cpp` (Student Diary):** A diary application with user authentication (login/register) to create, read, edit, and delete text entries.
* **`Program1.cpp` (LESCO Billing):** A utility billing system calculating electricity costs via specific unit slabs, applying taxes, and managing new connection applications.
* **`Program2.cpp` & `Program3.cpp` (Restaurant & Grocery Mart):** Point-of-sale systems that handle order quantities, shopping carts, GST, service charges, discounts, and loyalty points.
* **`Program4.cpp` & `Program5.cpp` (E-Commerce & Marketing):** Checkout and cost calculation systems handling delivery charges, payment processing fees, platform management costs, and ad budgets.

### Part 3: Arrays, Loops & Modular Functions
This section introduces array manipulation, sorting algorithms, and modular arithmetic operations.
* **`pro-1.cpp` & `pro-2.cpp`:** Programs to calculate the average, highest, and lowest scores from an array of student test marks.
* **`pro-3.cpp` & `pro-4.cpp`:** Mathematical calculators for computing exponents (power) and electrical voltage (current × resistance).
* **`pro-5.cpp` to `pro-12.cpp`:** Scripts utilizing arrays and loops to search for characters within a team squad, calculate string lengths, bubble-sort letters and test scores, count vowels, and verify leap years.

### Part 4: 2D Arrays, Strings & Advanced Algorithms
The final section highlights multi-dimensional arrays, pointer-based string manipulation, and function overloading.
* **`pro-13.cpp`, `pro-14.cpp`, & `pro-19.cpp`:** Matrix and array operations, including counting even/odd numbers, formatting a 2D seating chart, and summing all elements within a 2D matrix.
* **`pro-15.cpp` & `pro-16.cpp`:** Mathematical algorithms to find the Greatest Common Divisor (GCD) using the Euclidean algorithm and calculating a cricket batter's strike rate.
* **`pro-17.cpp`, `pro-18.cpp`, & `pro-24.cpp`:** Custom string manipulations bypassing standard libraries to calculate length, copy characters between arrays, and reverse a word in place.
* **`pro-20.cpp` to `pro-23.cpp`:** Advanced tasks including sequential 2D array subtraction, calculating bowling averages, and demonstrating function overloading to calculate the area of both squares and rectangles using the same function name.
